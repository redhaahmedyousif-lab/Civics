# 🇧🇭 منصة التربية للمواطنة — المرجع الشامل للاختبار الأول

منصة ويب تعليمية تفاعلية لطلاب **الصف الثاني الإعدادي** في مادة **التربية للمواطنة** — مملكة البحرين.
تصميم حديث، متجاوب مع الجوال، يدعم العربية بالكامل (RTL)، بخطّي **Cairo** و**Tajawal**، مع وضع ليلي.

## 📚 أقسام المنصة

| القسم | المحتوى |
|---|---|
| 🏠 **الواجهة الرئيسية** | عنوان المنصة، أزرار التنقل إلى الأقسام الثلاثة، ومؤشر تقدّم الطالب. |
| 📌 **مذكرة الأستاذ الرسمية** | المصطلحات (الشورى، الشأن العام) — المادتان (1) و(32) من الدستور — المحطات التاريخية (1919م، بدايات القرن العشرين، 1950م) — مبادئ وقيم نظام الحكم الخمسة — ضمانات القضاء وأهداف وصايا حكام آل خليفة — اختصاصات المجالس البلدية الثمانية. |
| 📖 **المذكرة العامة الشاملة** | ملخص تحليلي يدمج الكتاب المدرسي بمذكرة المعلم، مع جداول وجُمل حفظ و«خلاصة الخلاصة» قبل الاختبار. |
| ✍️ **بنك الـ 30 سؤالاً** | أسئلة مقالية مقسّمة إلى خمس مجموعات: المفاهيم، المواد الدستورية، القضاء والوصايا، مبادئ الحكم، المجالس والتاريخ. |

## ✨ مزايا بنك الأسئلة

- **مفتاح تبديل رئيسي** بين:
  - 🔒 **الامتحان الذاتي** — الحلول مخفية، مع مساحة لكتابة الإجابة قبل كشف الحل.
  - 👁️ **المراجعة** — جميع الحلول النموذجية ظاهرة.
- زر **إظهار/إخفاء الحل** لكل سؤال على حدة.
- **تقييم ذاتي** (✅ أتقنته / 🔁 أحتاج مراجعة) مع شريط تقدّم يُحفظ في المتصفح.
- **تصفية** حسب المجموعة و**بحث** فوري يتجاهل الهمزات والتشكيل.
- دعم **الطباعة** لأي قسم.

## 🛠️ التقنيات

- HTML5 + JavaScript (بدون أطر عمل، سريع وخفيف)
- Tailwind CSS (مُجمَّع مسبقاً في `assets/css/tailwind.css`) + أنماط مخصصة في `assets/css/style.css`
- لا يحتاج الموقع إلى أي خطوة بناء للنشر.

## 📁 هيكل المشروع

```
├── index.html                 # الصفحة الوحيدة (SPA بتوجيه عبر #)
├── assets/
│   ├── css/
│   │   ├── style.css          # التصميم المخصص
│   │   ├── tailwind.css       # Tailwind المُجمَّع
│   │   └── tailwind.src.css   # مصدر Tailwind
│   ├── js/
│   │   ├── data.js            # كل المحتوى: المذكرة والأسئلة والإجابات
│   │   └── app.js             # منطق التطبيق
│   └── img/favicon.svg
├── .github/workflows/pages.yml  # نشر تلقائي على GitHub Pages
├── tailwind.config.js
└── vercel.json
```

> لتعديل الأسئلة أو المذكرة يكفي تحرير `assets/js/data.js`.

## 🚀 التشغيل محلياً

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

إذا عدّلت أصناف Tailwind في `index.html` أو `app.js` أعد بناء ملف CSS:

```bash
npm install
npm run build:css
```

## 🌐 النشر

**GitHub Pages:** من إعدادات المستودع ← *Pages* ← اختر *Source: GitHub Actions*. سيُنشر الموقع تلقائياً عند كل دفع إلى الفرع `main`.

**Vercel:** استورد المستودع في Vercel واتركه بإعدادات «Other» دون أمر بناء؛ دليل الإخراج هو جذر المشروع.
